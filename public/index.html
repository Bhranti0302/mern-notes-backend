Quick start

Make your first request.

Use Swagger UI or Postman to explore the API. Protected endpoints require a valid login token or the authentication cookie supported by the backend.

1

Open the API reference

Browse endpoint paths, request bodies, parameters, and response descriptions.

2

Register or log in

Use the authentication endpoints to create an account and establish a session.

3

Authorize protected requests

Use the JWT with Swagger's Authorize control if using Bearer authentication.

4

Try notes and AI features

Create a note first, then use its ID for summarize, improve, and action-item endpoints.

Example · Create a note 
curl -X POST "http://localhost:5000/api/note" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "title": "Learn Express",
    "content": "Practice routes and middleware",
    "category": "Learning",
    "tags": ["Node.js", "Backend"]
  }'
Heads up: Replace YOUR_JWT_TOKEN with your token. This example uses Bearer authentication, which your middleware supports. The exact response body and status code depend on your controller implementation.
